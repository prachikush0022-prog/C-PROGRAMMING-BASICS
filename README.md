# 🏧 ATM Machine in C

## 📌 Project Description

This is a beginner-level ATM Machine project developed using the C programming language.

The program simulates basic ATM operations. It allows users to log in using a PIN and perform different banking operations such as checking account balance, depositing money, and withdrawing money.

## ✨ Features

- PIN Authentication
- Check Account Balance
- Deposit Money
- Withdraw Money
- Validate Deposit Amount
- Check Sufficient Balance Before Withdrawal
- Exit the ATM System

## 🛠️ Technologies Used

- **Programming Language:** C
- **IDE:** Visual Studio Code
- **Compiler:** GCC

## 📚 C Programming Concepts Used

This project uses the following basic C programming concepts:

1. Variables and Data Types
2. Input and Output (`printf()` and `scanf()`)
3. Conditional Statements (`if-else`)
4. Switch Case
5. While Loop
6. Arithmetic Operators
7. Logical Operators

## ⚙️ How the Program Works

1. The ATM displays a welcome message.
2. The user enters a PIN.
3. If the PIN is correct, the ATM menu is displayed.
4. The user can select one of the following operations:
   - Check Balance
   - Deposit Money
   - Withdraw Money
   - Exit
5. The program performs the selected operation.
6. The ATM menu continues until the user selects Exit.

## 🔐 Default PIN

**PIN:** `1234`

**Initial Balance:** ₹5000

## 💻 How to Run the Program

1. Download or clone this repository.
2. Open the project in Visual Studio Code.
3. Open the terminal.
4. Compile the program using GCC:

```bash
gcc ATM_Machine.c -o ATM_Machine
```

5. Run the program:

**Windows:**
```bash
ATM_Machine.exe
```

**Linux / macOS:**
```bash
./ATM_Machine
```
